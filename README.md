# Universal IPTV

A modern Android IPTV streaming application built with Kotlin and ExoPlayer (Media3).

## Features

- **IPTV Streaming**: Stream channels using ExoPlayer with HLS and progressive media support
- **M3U/BIN Import**: Import playlist files from device (supports multiple file selection)
- **URL Loading**: Load playlists directly from M3U URLs
- **Category Organization**: Channels organized by categories with search functionality
- **Online/Offline Status**: Automatic stream status checking with visual badges
- **Multi-language**: Supports English and Bahasa Indonesia
- **Download Playlist**: Download playlist content for offline reference
- **Modern UI**: Material Design 3 with clean, modern interface

## Tech Stack

- **Language**: Kotlin
- **Player**: AndroidX Media3 (ExoPlayer)
- **Database**: Room
- **UI**: Material Design 3
- **Network**: OkHttp
- **Architecture**: MVVM with LiveData

## Building

```bash
./gradlew assembleDebug
```
